# Creative AI Skills

A collection of five custom skills for video and music prompting.

| Skill | Purpose |
| --- | --- |
| [Seedance 2.5](seedance-25/SKILL.md) | Video prompts, reference mapping, storyboards, extensions, and edits. |
| [MiniMax H3](h3-prompt-writing/SKILL.md) | Audiovisual prompts, camera and action direction, editing, and validation. |
| [Kling 4](kling-4-prompting/SKILL.md) | Kling 4.0 and Flash prompts with explicit reference roles. |
| [MiniMax Music 3.0](minimax-music-30/SKILL.md) | Song prompts, arrangement guidance, genre references, and 1,000 templates. |
| [Suno Song Builder](suno-song-builder/SKILL.md) | Song concepts, original lyrics, instrumental scores, and Suno prompt packages. |

## Contents

Each folder contains its `SKILL.md` entry point and supporting references. Some skills also include validation scripts and templates. Follow each skill's own instructions when using it.

## Local installation

Copy the desired skill folder into `~/.codex/skills/`. Preserve the complete folder, including its references, scripts, and templates. Back up any existing copy before replacing it.

These are prompting resources and validation helpers; they do not include model weights or API credentials. Model and service availability should be checked on the relevant platform.
