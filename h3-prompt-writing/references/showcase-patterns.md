## How To Use This Index

- Match the user's task to one or two rows.
- Borrow the planning pattern, not the source prompt's characters, brands, wording, or aesthetic.
- Rebuild the request in the official mode grammar and target-surface serialization.
- Rows marked **Partial** explicitly say “Partial prompt — expand as needed” on the source page. Supply the missing timeline, audio, preservation, and schema details.

Input counts below reflect attached source assets in the page's Input column. “Complete” means only that the page did not label the prompt partial; it does not override the official grammar. IDs 1–45 preserve the August 7 local index for stable cross-reference. ## Cross-Example Prompting Patterns

The 58 demonstrations repeatedly support this planning order:

1. format, duration, and composition intent;
2. explicit role for every asset;
3. scene, task, or edit target;
4. shot order or timed beats;
5. performance and camera behavior;
6. transition bridges and intermediate states;
7. visual treatment and legibility;
8. dialogue, physical sound, voice, and music;
9. preservation and exclusion clauses;
10. final payoff, frame, title, product, or UI hold.

Common successful mechanisms include:

- fixed outer geometry with controlled internal motion;
- literal text synchronized to focus or UI state, with approved text plates used as images when native typography fails;
- strict identity/product locks paired with flexible motion/style references;
- motion and camera sources separated from destination appearance;
- selective transformations with named untouched regions;
- physical transition bridges based on shared texture, shape, light, motion, or pre-existing geometry;
- exact change-plus-preserve editing language, especially for direct AR compositing and industrial edits;
- compact timed beats for causal UI, game input, robotic, and mechanical actions;
- one shared motif or geometry carried across a brand system instead of disconnected motion-design cards;
- a declared topology: default cuts, or one consistent continuous path without contradictory shot blocks.
