# 9. Skill rulebook (enforceable rules)

1. **Pin and detect the version.** Read `THREE.REVISION`, and gate: `<165` legacy lights; `<180` `RGBELoader`; `<183` `PostProcessing`; `≥186` no `PCFSoftShadowMap`; `≥187` with pmndrs → warn about the peer range.
2. **Colour:** albedo-class maps `SRGBColorSpace`; data maps untouched (`NoColorSpace`); HDR `LinearSRGBColorSpace`; exactly one output transform.
3. **Units:** metres; lights set via `.power` (lm) or candela/nits/lux; `decay = 2`; pre-expose rather than feed absolute sun luminance into half-float buffers.
4. **Lighting:** every photoreal scene has `scene.environment`; no `AmbientLight`/`HemisphereLight` fill; one shadow-casting key light with a fitted frustum; GI from lightmaps, `LightProbeGrid` or SSGI, never from a raised ambient term.
5. **Shadows:** `PCFShadowMap`; fit the frustum before touching bias; `normalBias ≈ 1 texel`; |bias| × depth range ≤ about 1 cm at human scale.
6. **Materials:** change lighting inputs, never outputs; metals use the F0 table; roughness ≥ 0.05 except mirrors and glass; transmission (not opacity) for glass; IOR from the table, clamped to 2.333.
7. **Post:** AO into indirect light only; temporal effects before DOF and bloom; bloom on linear HDR; grain, chromatic aberration and vignette after tone mapping; TRAA whenever any stochastic effect is on.
8. **Assets:** UASTC for normals and ORM, ETC1S for colour, Meshopt geometry; no simplify, join or palette on hero assets; dispose everything and check `renderer.info.memory`.
9. **Stylized looks:** pick the departure per layer (shading, edges, colour, post) and keep everything else physical. Flat-colour palettes use `NoToneMapping` (values ≤ 1) or `NeutralToneMapping`, never AgX. Toon ramps use `NearestFilter`. Line widths scale with DPR. Pixel art uses an orthographic camera, frustum snapping and no AA.
10. **Post-pass depth:** in fullscreen post nodes, convert depth with the *scene* camera's near/far (`reference( 'near', 'float', camera )` or `pass.getViewZNode()`), never the global `cameraNear`/`cameraFar`.
11. **Animation & interaction (`§12`):** use `THREE.Timer` (`Clock` deprecated r183) and `renderer.setAnimationLoop()`. Apply procedural bone overrides *after* `mixer.update(dt)`. Clone skinned models with `SkeletonUtils.clone()`, never `model.clone()`. Add `TransformControls` gizmos via `scene.add(tc.getHelper())`. Filter raycasts with `mesh.layers.enable(1)` + `raycaster.layers.set(1)`, never `.set(1)` on a visible mesh.
12. **Batching, performance & compute (`§13`):** read `renderer.info.render.drawCalls` on WebGPU (`render.calls` is cumulative passes). Use `InstancedMesh` for identical geometry, `BatchedMesh` (`addGeometry` + `addInstance`) for mixed geometries sharing a material. Precompile with `await renderer.compileAsync(scene, camera)`. On WebGPU, sized points require `Sprite` + `PointsNodeMaterial`, and r187 struct storage buffers require `.element(i).get('member')`.
13. **Custom shaders & TSL (`§14`):** prefer TSL (`three/tsl`) + `*NodeMaterial` (`three/webgpu`) over `ShaderMaterial` / `onBeforeCompile`. Build vertex displacement on `positionLocal` (never `positionGeometry`) and sync shadow casters with `castShadowPositionNode`. In r187 TSL, use `normalView` / `normalWorld` (`transformedNormal*` removed). On WebGL `ShaderMaterial`, always include `<tonemapping_fragment>` and `<colorspace_fragment>`.
14. **React Three Fiber (`§15`):** pass `shadows="percentage"` (boolean `shadows` triggers the removed `PCFSoftShadowMap` warning) and set `toneMapping: THREE.AgXToneMapping` (or `NeutralToneMapping`). Never call React `setState` or `state.clock.getElapsedTime()` inside `useFrame`; use the `delta` parameter and `state.clock.elapsedTime`. For WebGPU `<Canvas>`, pass an async `gl` factory that awaits `renderer.init()` and call `extend(THREE)`.
15. **Verification gate:** a change counts as verified only after a browser render, a frame-time measurement (`renderer.info.render`, GPU timer queries / the Inspector), and a visual comparison against a reference. A successful build or console silence is not evidence.
