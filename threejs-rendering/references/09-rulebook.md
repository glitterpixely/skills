# 9. Skill rulebook (enforceable rules)

1. **Pin and detect the version.** Read `THREE.REVISION`, and gate: `<165` legacy lights; `<180` `RGBELoader`; `<183` `PostProcessing`; `≥186` no `PCFSoftShadowMap`; check pmndrs `postprocessing` `peerDependencies.three` dynamically (`6.39.6` supports `<0.188.0`, compatible with r187).
2. **Colour:** albedo-class maps `SRGBColorSpace`; data maps untouched (`NoColorSpace`, including `bumpMap`, `alphaMap`, `sheenRoughnessMap`); HDR `LinearSRGBColorSpace`; exactly one output transform.
3. **Units & depth:** metres; lights set via `.power` (lm) or candela/nits/lux; `decay = 2`; pre-expose rather than feed absolute sun luminance into half-float buffers. Use `reversedDepthBuffer: true` for large-scale worlds on `WebGPURenderer` + `RenderPipeline` (with `sky.renderOrder = -1e6; sky.material.depthTest = false;` on `SkyMesh`), never with pmndrs `EffectComposer`.
4. **Lighting:** every photoreal scene has `scene.environment` (hide `SkyMesh.showSunDisc` during PMREM bakes); no `AmbientLight`/`HemisphereLight` fill; one shadow-casting key light with a fitted frustum; GI from lightmaps, `LightProbeGrid` or SSGI, never from a raised ambient term; `ClusteredLighting` for dozens of local lights on WebGPU.
5. **Shadows:** `PCFShadowMap`; fit the frustum before touching bias (`fitDirectionalShadow` zero-import helper); `normalBias ≈ 1 texel`; |bias| × depth range ≤ about 1 cm at human scale.
6. **Materials:** change lighting inputs, never outputs; metals use the F0 table; roughness ≥ 0.05 except mirrors and glass; choose transparency deliberately (`alphaTest`, `alphaHash`, `backdropNode`, `oitPass`, or `transmission` + `ior` + `thickness` + `dispersion`); `reflectivity` clamps above `ior = 2.333` (for higher-IOR dielectrics use `ior` directly).
7. **Post:** AO into indirect light only; temporal effects (`traa` / `taau`) before DOF and bloom; bloom on linear HDR; grain, chromatic aberration, vignette, `lut3D` and `fsr1` after tone mapping; wrap `oitPass` in `vec4( scenePass )` before feeding post nodes; on pmndrs, place `SMAAEffect` in a separate final `EffectPass` from `ChromaticAberrationEffect` and keep `n8ao.configuration.halfRes = false` on r187.
8. **Assets:** UASTC for normals and ORM, ETC1S for colour, Meshopt geometry (`gltf-transform` CLI or Node `@gltf-transform/functions`); `GaussianSplat` + `SPZLoader` for first-party 3DGS on `WebGPURenderer`; no simplify, join or palette on hero assets; dispose everything (including `.disposeBoundsTree?.()`, `StorageTexture`, `RenderTarget`, `RenderPipeline`) and check `renderer.info.memory`.
9. **Stylized looks:** pick the departure per layer (shading, edges, colour, post) and keep everything else physical. Flat-colour palettes use `NoToneMapping` (values ≤ 1) or `NeutralToneMapping`, never AgX. Toon ramps use `NearestFilter`. Line widths scale with DPR. Pixel art uses an orthographic camera, frustum snapping and no AA.
10. **Post-pass depth:** in fullscreen post nodes, convert depth with the *scene* camera's near/far (`reference( 'near', 'float', camera )` or `pass.getViewZNode()`), never the global `cameraNear`/`cameraFar`.
11. **Animation, raycasting, controls & XR (`§12`):** use `THREE.Timer` (`Clock` deprecated r183) and `renderer.setAnimationLoop()`. Apply procedural bone overrides *after* `mixer.update(dt)`. Clone skinned models with `SkeletonUtils.clone()`, never `model.clone()`. Add `TransformControls` gizmos via `scene.add(tc.getHelper())`. Accelerate dense or `BatchedMesh` raycasts with `three-mesh-bvh` (`firstHitOnly = true`), and filter picks with `mesh.layers.enable(1)` + `raycaster.layers.set(1)`, never `.set(1)` on a visible mesh.
12. **Batching, performance & compute (`§13`):** read `renderer.info.render.drawCalls` on WebGPU (`render.calls` is cumulative passes) and inspect live passes with `Inspector`. Use `InstancedMesh` for identical geometry, `BatchedMesh` (`addGeometry` + `addInstance` or `SceneOptimizer.toBatchedMesh()`) for mixed geometries, `BundleGroup` (`three/webgpu`) for static render bundles, and `NodeMaterialInstance` with `reference('userData.x', ...)` on `mesh.userData` for shadow-casting per-object `colorNode` overrides. Precompile with `await renderer.compileAsync(scene, camera)`. On WebGPU, sized points require `Sprite` + `PointsNodeMaterial`, and r187 struct storage buffers require `.element(i).get('member')`.
13. **Custom shaders & TSL (`§14`):** prefer TSL (`three/tsl`) + `*NodeMaterial` (`three/webgpu`) over `ShaderMaterial` / `onBeforeCompile` (convert legacy GLSL helpers via `Transpiler` + `GLSLDecoder` + `TSLEncoder`). Declare explicit return types in `Fn( fn, { ..., return: 'float' } )` when using early `Return()`. Build vertex displacement on `positionLocal` (never `positionGeometry`) and sync shadow casters with `castShadowPositionNode`. In r187 TSL, use `normalView` / `normalWorld` (`transformedNormal*` removed). On WebGL `ShaderMaterial`, always include `<tonemapping_fragment>` and `<colorspace_fragment>`.
14. **React Three Fiber (`§15`):** pass `shadows="percentage"` (boolean `shadows` triggers the removed `PCFSoftShadowMap` warning) and set `toneMapping: THREE.AgXToneMapping` (or `NeutralToneMapping`). Never call React `setState` or `state.clock.getElapsedTime()` inside `useFrame`; use `delta`, `state.clock.elapsedTime`, and Zustand transient `store.subscribe` + `invalidate()` under `frameloop="demand"`. For WebGPU `<Canvas>`, pass an async `gl` factory that awaits `renderer.init()`, call `extend(THREE)`, and run TSL `RenderPipeline` inside `useFrame(..., 1)`.
15. **Verification gate:** a change counts as verified only after a browser render, a frame-time measurement (`renderer.info.render`, GPU timer queries / the Inspector), and a visual comparison against a reference. A successful build or console silence is not evidence.
